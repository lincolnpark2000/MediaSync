# 订阅功能详解

[← 返回主页](../README.md)

---

## 概述

订阅功能允许你追踪关注的创作者、收藏夹或播放列表，自动检测新发布的内容并下载。是 MediaSync 的 **Pro** 功能。

---

## 支持的订阅类型

| 平台 | 订阅类型 | 说明 |
|:---|:---|:---|
| Bilibili | 收藏夹 | 追踪收藏夹新增视频 |
| Bilibili | 稍后再看 | 追踪稍后再看列表变化 |
| Bilibili | 关注 UP 主 | 追踪 UP 主新发布的视频 |
| YouTube | 播放列表 | 追踪播放列表新增视频 |
| YouTube | 关注频道 | 追踪频道新发布的视频 |
| 抖音 | 收藏 | 追踪收藏列表变化 |
| 抖音 | 关注博主 | 追踪博主新作品 |
| 小红书 | 收藏 | 追踪收藏笔记变化 |
| Pinterest | 画板 | 追踪画板新增 Pin |

## 创建订阅

1. 在侧边栏选择 **订阅同步**
2. 点击 **创建订阅**
3. 选择平台和订阅类型
4. 配置扫描参数：
   - **扫描间隔** — 多久检查一次新内容
   - **扫描项数上限** — 每次扫描的最大项数
   - **自动下载** — 发现新内容时是否自动下载
5. 确认创建

## 扫描模式

### 标准扫描

按照配置的项数限制扫描最新内容。适合日常使用。

### 增量扫描

智能识别已经处理过的内容，只扫描新增的部分。避免重复处理，提高效率。

### 强制扫描

忽略增量标记，重新扫描所有内容。适合需要补全遗漏内容的场景。

## 订阅管理

在订阅面板中可以：

- **查看状态** — 每个订阅的运行状态、最后扫描时间、已发现/已下载数量
- **暂停 / 恢复** — 临时暂停或恢复订阅的自动扫描
- **手动检查** — 立即触发一次扫描
- **查看监控项** — 查看订阅发现的所有媒体及其下载状态
- **修改配置** — 调整扫描间隔、项数限制等参数
- **删除订阅** — 删除订阅（已下载的历史会保留）

---

## 统计面板

订阅页面顶部显示全局统计：

- 总订阅数
- 活跃订阅数
- 总监控项数
- 已下载项数
