## 概述

MediaSync 内置通知系统，可以在任务完成、直播状态变化、录制结束等关键节点，通过 **Telegram Bot** 或 **企业微信应用消息** 主动推送消息。

如果启用交互命令，用户还可以直接在聊天窗口中发送链接或命令，让 MediaSync 远程执行 **解析、下载、创建订阅、查看状态、添加直播录制** 等操作。

## 支持能力总览

| 渠道 | 接收通知 | 发送命令 | 交互方式 | 适合场景 |
|:---|:---:|:---:|:---|:---|
| Telegram Bot | ✅ | ✅ | 封面图、内联按钮、分辨率选择 | 个人使用、群组协作、远程快速操作 |
| 企业微信 | ✅ | ✅ | 应用消息、文本命令、回调接收 | 团队通知、企业内网部署 |

> Telegram 的交互体验更完整，支持直接点按钮执行下载、订阅和画质选择。
>
> 企业微信更偏向稳定的消息触达与文本命令控制，不支持 Telegram 那样的内联按钮。

## 可触发的通知事件

在 **设置 → 通知设置** 中，你可以按事件开启或关闭通知范围。当前主要覆盖以下场景：

- **下载完成** — 单个下载成功，或订阅扫描后产生的批量下载摘要
- **下载失败** — 任务创建成功但下载过程中失败
- **直播开始** — 直播间状态从未开播切换到开播
- **直播结束** — 直播间状态从开播切换为结束
- **开始录制** — 监控命中后自动开始录制
- **录制完成** — 录制结束并生成本地文件
- **录制失败** — 录制过程中出现异常

如果在通知设置中配置了 **服务器公网地址**，下载完成和录制完成消息还会自动带上：

- **在线播放链接**
- **本地下载链接**

## Telegram 配置

### 基础配置

1. 打开 Telegram，联系 `@BotFather` 创建一个机器人。
2. 获取 **Bot Token**。
3. 获取你自己的 **Chat ID**，或目标群组的 **Chat ID**。
4. 打开 MediaSync：**设置 → 通知设置 → Telegram**。
5. 填入 `Bot Token` 和 `Chat ID`。
6. 如有需要，填写代理地址。
7. 点击 **测试通知**，确认消息可以正常送达。

### 命令模式

启用 **交互命令** 后，Telegram Bot 可以接收以下操作：

- **直接发送链接** — 系统自动识别视频、合集、直播间或用户主页
- **/解析 · /analyze · /a [链接]** — 解析内容信息
- **/下载 · /download · /d [链接]** — 直接下载最佳画质
- **/订阅 · /subscribe · /s [链接]** — 把链接加入订阅同步
- **/状态 · /status · /st** — 查看当前运行状态
- **/帮助 · /help · /h** — 查看帮助信息

Telegram 机器人还有几个额外优势：

- 输入 `/` 时会自动弹出命令提示
- 直接发送链接后会出现操作按钮
- 单视频支持 **选择分辨率下载**
- 通知消息可附带缩略图 / 封面图

## 企业微信配置

### 基础配置

1. 在企业微信管理后台创建一个自建应用。
2. 记录以下参数：
   - `CorpID`
   - `Secret`
   - `AgentId`
3. 打开 MediaSync：**设置 → 通知设置 → 企业微信**。
4. 填入以上参数并保存。
5. 点击 **测试通知**，确认应用消息可以正常收到。

### 启用文本命令

如果只需要接收通知，上面的基础配置已经足够。

如果还需要在企业微信中发送命令控制 MediaSync，则除了开启 **启用交互命令** 之外，还需要为应用配置回调参数：

- **回调地址**：`你的 MediaSync 公网地址/api/notifications/wechat/callback`
- **Token**
- **EncodingAESKey**

当前后端会在以下配置文件中读取这两个回调参数：

```json
{
  "channels": {
    "wechat": {
      "enabled": true,
      "corp_id": "你的 CorpID",
      "corp_secret": "你的 Secret",
      "agent_id": "你的 AgentId",
      "token": "你的回调 Token",
      "encoding_aes_key": "你的 EncodingAESKey",
      "enable_commands": true
    }
  }
}
```

配置文件路径：`/app/data/notification_config.json`

> 如果你使用反向代理或公网域名，请确保企业微信可以访问到上面的回调地址。

## 远程命令说明

### 直接发链接

把链接直接发送给机器人时，MediaSync 会先判断链接类型，再给出适合的操作：

- **视频 / 笔记 / 帖子** → 解析、下载、选择分辨率
- **合集 / 播放列表 / 收藏夹** → 添加订阅、查看内容
- **直播间链接** → 添加直播录制
- **用户主页 / 频道主页** → 添加订阅，直播平台还可尝试添加直播录制

### 命令列表

| 命令 | 说明 |
|:---|:---|
| `/解析` `解析` `/analyze` `/a` | 解析链接并查看结果 |
| `/下载` `下载` `/download` `/d` | 按最佳画质创建下载任务 |
| `/订阅` `订阅` `/subscribe` `/s` | 创建订阅同步任务 |
| `/状态` `状态` `/status` `/st` | 查看活跃任务、已完成任务、订阅数、录制数 |
| `/帮助` `帮助` `/help` `/h` | 查看帮助说明 |

### 交互差异

- **Telegram**：支持操作按钮、画质选择、消息编辑、回调按钮
- **企业微信**：支持文本命令和普通文本回复，不支持 Telegram 式内联按钮

## 模板变量

通知模板支持使用 `{变量名}` 插入动态内容。常见变量如下：

| 事件 | 常用变量 |
|:---|:---|
| 下载完成 | `{title}` `{platform}` `{resolution}` `{file_size}` `{file_path}` `{stream_url}` `{download_url}` |
| 下载失败 | `{title}` `{platform}` `{error}` |
| 直播开始 | `{host_name}` `{room_name}` `{platform}` `{room_url}` |
| 直播结束 | `{host_name}` `{room_name}` `{platform}` |
| 开始录制 | `{host_name}` `{room_name}` `{quality}` |
| 录制完成 | `{host_name}` `{room_name}` `{duration}` `{file_size}` `{file_path}` `{stream_url}` `{download_url}` |
| 录制失败 | `{host_name}` `{error}` |

如果 **服务器公网地址** 留空，那么消息中的播放 / 下载链接会自动替换为提示文本，不会生成不可访问的死链接。

## 使用建议

- **个人用户优先选 Telegram**：部署简单，交互完整，支持直接点按钮操作。
- **团队协作优先选企业微信**：适合企业网络、团队接收统一通知。
- **启用公网地址**：这样通知里的播放和下载链接才可直接使用。
- **先发测试通知**：确认消息通道、代理和外网访问都已正常。
- **企业微信命令模式要做回调验证**：只有消息回调能打通，文本命令才会生效。
