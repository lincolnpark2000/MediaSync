# 收藏与关注功能详解

[← 返回主页](../README.md)

---

## 概述

MediaSync 可以直接连接你的平台账号，浏览你的收藏夹、关注列表、播放列表等内容，并支持从列表中直接选中视频进行批量下载。

---

## 支持的平台与内容类型

### Bilibili（B站）

- **收藏夹** — 浏览所有收藏夹和其中的视频
- **稍后再看** — 查看稍后再看列表
- **关注 UP 主** — 浏览关注的 UP 主列表，查看其视频
- **合集 / 系列** — 浏览 UP 主的合集和系列视频

> 需要先在 **设置 → Cookies** 中完成 B 站登录（扫码登录或 Cookie 导入）。

### YouTube

- **播放列表** — 浏览公开和个人播放列表
- **关注频道** — 查看订阅的频道
- **喜欢的视频** — 浏览点过赞的视频

> 需要先在 **设置 → Cookies** 中导入 YouTube Cookie。

### 抖音

- **收藏列表** — 浏览收藏的视频
- **关注博主** — 浏览关注的博主及其作品
- **合集 / 系列** — 浏览博主的合集和系列

> 需要先在 **设置 → Cookies** 中导入抖音 Cookie。

### 小红书

- **收藏笔记** — 浏览收藏的笔记（图片 / 视频）

> 需要先在 **设置 → Cookies** 中导入小红书 Cookie。

### Pinterest

- **画板** — 浏览画板中的所有 Pin

> 需要先在 **设置 → Cookies** 中导入 Pinterest Cookie。

---

## 使用方法

1. 在侧边栏选择 **收藏** → 选择对应平台
2. 系统会加载你的收藏夹 / 关注列表
3. 点击具体的收藏夹或 UP 主，查看视频列表
4. 勾选需要下载的视频
5. 点击 **批量下载**

## 分页与加载

- 列表支持 **滚动加载更多** 和 **分页浏览**
- B站合集支持分页缓存，避免重复请求
- 抖音支持游标分页，可持续加载更多内容
