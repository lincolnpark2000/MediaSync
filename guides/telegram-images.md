# Telegram 公开频道图片

在下载页粘贴公开频道链接（`https://t.me/频道名`）或消息链接（`https://t.me/频道名/消息编号`）并解析。

- 频道按较新消息优先列出图片，可继续加载较早消息。
- 消息中的相册保留图片顺序，可逐张选择或批量下载。
- 图片保留来源消息链接，可使用现有图片预览和本地、服务器下载。
- 支持 `t.me/s/频道名` 和 `telegram.me` 形式。

未登录时读取 Telegram 无需登录即可访问的公开网页，图片清晰度取决于网页提供的版本。

## Telegram 账号登录

1. 打开设置 → Cookie → tg账号卡片。点击“API 配置”可展开默认/个人 API 设置。
2. 默认使用共享应用 API，无需填写 API ID 和 API Hash，可直接扫码。也可在 https://my.telegram.org/apps 获取个人 API ID 和配套 API Hash，在设置页保存后使用个人 API。
3. 点击扫码登录，在手机 Telegram 的设置 → 设备 → 连接桌面设备中扫描并确认。
4. 若开启两步验证，在页面输入两步验证密码；密码仅用于此次登录，不保存。
5. 显示已登录后，重新解析频道用户名链接或消息链接。系统使用该账号的访问权限读取消息，并通过 Telegram API 下载照片。

二维码过期可刷新。刷新状态会验证现有会话；退出登录会撤销本服务的 Telegram 会话。
登录后点击“账号信息”展开详情，可刷新状态或退出；收起时也可直接点击“退出”。退出保留 API 配置。
共享的是应用 API，登录的仍是用户自己的账号。共享 API 可能受到 Telegram 限流或限制，遇到相关报错可改用个人 API。已有个人配置会继续优先使用；点击“改用默认共享 API”可清除个人配置。已登录时需先退出，再切换 API。
API 配置和会话保存在服务数据目录，Docker 重启后保留，不包含在镜像和普通配置导出中。
账号照片的预览及下载使用有效期 24 小时的签名地址，退出或重新登录后旧地址失效，重新解析即可。

目前支持有用户名的频道、超级群组及其消息链接；邀请链接、`t.me/c/...` 私有消息链接、视频和文件附件暂不支持。
系统不会自动加入频道。账号必须已有读取权限。Telegram Bot 通知配置与此登录独立。

公开网页模式每次最多检查 3 页消息，每次最多返回 100 张图片；单次解析会话最多扫描 100 页。
分页缓存保留 30 分钟，过期后重新解析。若近期页面只有文字或视频，可直接提供图片消息链接。
网页媒体地址失效后，也需要重新解析来源消息。
