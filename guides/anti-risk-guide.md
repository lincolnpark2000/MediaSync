# B站防风控配置指南

[← 返回主页](../README.md)

---

## 概述

当频繁请求 B 站 API 时（如批量获取关注列表、收藏夹内容等），可能触发 B 站的风控机制，导致请求被拒绝或账号受限。MediaSync 内置了完善的防风控系统，帮助你安全地使用 B 站相关功能。

---

## 防风控机制

### 智能延迟控制

每次请求之间自动插入随机延迟，模拟人类操作节奏，避免短时间内发送大量请求。

### 请求头轮换

自动轮换请求头中的 User-Agent、Referer 等字段，降低被识别为自动化工具的风险。

### 风控状态监测

实时监测 B 站 API 的返回状态，一旦检测到风控信号，自动暂停并等待恢复。

---

## 预设方案

在 **设置** 中可以选择不同的预设方案：

| 方案 | 请求延迟 | 适用场景 | 风险等级 |
|:---|:---|:---|:---|
| **快速** | 0.3 ~ 1.0 秒 | 少量内容，快速获取 | 较高 |
| **标准**（推荐） | 0.5 ~ 2.0 秒 | 日常使用 | 适中 |
| **安全** | 1.0 ~ 3.0 秒 | 大量内容获取 | 较低 |
| **极端安全** | 2.0 ~ 5.0 秒 | 高度敏感操作 | 最低 |

---

## 配置方法

1. 打开 Web UI
2. 系统会根据操作自动应用防风控策略
3. 如需调整，可在相关设置中选择预设方案

## 建议

- 一般情况下使用 **标准** 方案即可
- 如果需要批量获取大量关注列表或收藏夹内容，建议切换到 **安全** 或 **极端安全** 方案
- 如果遇到风控提示，等待一段时间后再重试
- 保持 B 站 Cookie 的有效性，过期的 Cookie 更容易触发风控
