# 下载功能详解

[← 返回主页](../README.md)

---

## 概述

MediaSync 基于强大的 [yt-dlp](https://github.com/yt-dlp/yt-dlp) 引擎，支持多平台视频、音频、图片的解析与下载。提供单个链接解析和批量链接解析两种模式。

---

## 单个链接下载

1. 在侧边栏选择 **媒体解析 → 单个解析**
2. 将视频链接粘贴到输入框
3. 点击 **解析** 按钮，系统自动识别平台并获取视频信息
4. 选择所需的 **格式**（分辨率、编码等）
5. 点击 **下载** 开始下载

### 支持的链接格式

- YouTube 视频 / 播放列表链接
- B站视频 / 合集链接
- 抖音分享链接
- 小红书笔记链接
- Twitter/X 推文链接
- Instagram 帖子 / Reels 链接
- Pinterest Pin 链接

---

## 合集 / 收藏夹 / 播放列表链接

单个解析页不仅支持单视频，也支持合集、收藏夹和播放列表链接。

当解析到的是这类集合型链接时，你可以：

- 先查看集合内的媒体内容
- 直接从结果页创建订阅
- 批量下载其中的内容

这类链接更适合配合 **订阅同步** 一起使用，后续新增内容可以自动增量追踪。

## 批量下载

1. 在侧边栏选择 **媒体解析 → 批量解析**
2. 粘贴多个链接（每行一个）
3. 点击 **全部解析**
4. 统一选择格式后批量下载

## 格式选择

解析完成后，你可以选择：

- **视频格式**：MP4、MKV、WebM 等
- **分辨率**：4K、1080p、720p、480p、自动最佳画质
- **编码器**：H.264、H.265/HEVC、VP9、AV1
- **音频格式**：MP3、AAC、OPUS
- **附加选项**：
  - 仅下载音频
  - 下载字幕
  - 下载封面图

如果你启用了 **Telegram 交互命令**，在机器人里发送视频链接后，还可以直接通过按钮选择分辨率并发起下载。

## 下载任务管理

在 **下载任务** 页面，你可以：

- 查看所有下载任务的状态和进度
- 按状态筛选：全部 / 活跃 / 已完成 / 出错
- 按平台筛选：B站 / 抖音 / YouTube / 小红书 / Twitter / Instagram
- 按时间排序：最新优先 / 最早优先
- **批量操作**：选中多个任务进行暂停 / 恢复 / 取消 / 删除
- 查看实时下载速度和预计完成时间

### 任务状态说明

| 状态 | 说明 |
|:---|:---|
| 等待中 | 任务已创建，等待下载 |
| 下载中 | 正在下载，显示进度和速度 |
| 处理中 | 下载完成，正在合并/转码 |
| 已完成 | 下载成功 |
| 已暂停 | 用户手动暂停 |
| 出错 | 下载失败，可查看错误信息 |
| 已取消 | 用户手动取消 |

## 下载设置

在 **设置 → 下载设置** 中可以配置：

- **最大并发下载数** — 同时进行的下载任务数量
- **单任务速度限制** — 每个下载任务的最大速度（KB/s）
- **默认画质** — 解析时的默认画质选择
- **代理设置** — 配置用于访问海外平台的代理

在 **设置 → 下载路径** 中可以配置：

- **路径模板** — 为单个视频、合集、频道分别设置保存目录
- **文件名模板** — 自定义下载媒体文件名，默认值为 {title}
- **通用变量** — {platform} {uploader} {playlist_name} {title} {date} {year} {month} {day} {time} {random}

如果已经配置 **通知设置**，下载完成和下载失败也可以自动推送到 Telegram / 企业微信。
