# 文件管理详解

[← 返回主页](../README.md)

---

## 概述

MediaSync 内置文件浏览器，可以直接在 Web UI 中管理下载的视频文件和直播录制文件，支持在线播放、搜索、排序等操作。

---

## 功能

### 目录浏览

- **下载文件** — 浏览 `/downloads` 目录下的所有已下载内容
- **直播录制** — 浏览 `/live_recordings` 目录下的录制文件
- 多标签页导航，可同时打开多个文件夹
- 支持面包屑路径导航

### 文件操作

- **在线播放** — 基于 ArtPlayer 的内置视频播放器，直接在浏览器中播放
- **图片预览** — 直接预览下载的封面图和图片
- **排序** — 按名称、大小、修改时间排序
- **搜索** — 快速搜索文件名
- **文件夹下载** — 将文件夹打包为 ZIP 下载
- **删除文件或文件夹** — 点击操作栏的删除按钮，确认后永久删除；删除文件夹会同时删除其所有子文件和子文件夹，操作不可撤销

### 文件分类

系统自动识别文件类型：
- 🎬 视频文件（MP4、MKV、WebM 等）
- 🎵 音频文件（MP3、AAC、FLAC 等）
- 🖼️ 图片文件（JPG、PNG、WebP 等）
- 📄 其他文件

---

## 使用方法

1. 在侧边栏选择 **文件浏览** → **下载文件** 或 **直播录制**
2. 浏览文件目录结构
3. 点击视频文件即可在线播放
4. 点击图片文件即可预览
